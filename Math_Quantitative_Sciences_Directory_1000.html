About the data. Entries were assembled from first-hand knowledge and cross-checked against institutional and project pages, CRAN task views, the SciML package index, the Jupyter documentation tree and university course catalogues. Categories overlap by design — a system like SageMath appears under both computer algebra and programming environments — so per-category counts sum to more than the entry total.

Accuracy limits. Pricing and free tiers change often; treat the access labels as a rough guide and confirm on the vendor's site before committing. Regional availability, institutional licences and student discounts are not modelled. Some corporate and cloud hosts answer browsers but refuse automated probes, so a link that fails in a script may still open normally for you.

Adding entries. Use “+ Add resource”. Additions persist in localStorage on this machine only, are merged on load, and can be cleared from the browser's site settings. Export CSV gives you a flat file of whatever is currently filtered.
